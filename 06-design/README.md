# 06 — Design

The Main Solution Design (SDD) describes the whole system. A Technical Design Document (TDD) describes one bounded component, integration, or technical capability. Security and deployment designs may be separate when their depth or ownership warrants it.

Draft design and proposed decisions may evolve together. Final authority remains: accepted EDRs and contracts, then approved design. A TDD inherits MAIN constraints and cannot override an accepted global decision.

Do not confuse Technical Design Documentation with Test-Driven Development; the latter is an optional implementation practice.
