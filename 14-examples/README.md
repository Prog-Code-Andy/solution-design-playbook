# 14 — Examples

Examples demonstrate expected structure and state transitions; they are not instructions and contain no approval for a real project.

- `single-scope-project`: one MAIN scope from Discovery through a design draft.
- `multi-scope-enterprise-project`: MAIN plus Entra ID, Octopus, scanning, platform, and reporting scopes.
- `remediation-example`: a confirmed defect classified into a bounded REM package.

Each example contains a numbered run sequence mapping user intent to the canonical prompts.
