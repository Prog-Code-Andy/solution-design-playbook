# Single-Scope Run Sequence

1. `000-start-here` — detect a new project.
2. `010-initialize-project` — create MAIN and YAML state.
3. `020-register-requirements` — register the documentation brief.
4. `030-main-discovery` — clarify audience, content, ownership, and success.
5. `040-review-main-discovery` — approve MAIN Discovery.
6. `050-decompose-scopes` — approve `single-scope` mode.
7. `080`/`090` — create and accept only durable decisions that are needed.
8. `100-define-contracts` — define content metadata only if an exact boundary is needed.
9. `110-create-main-solution-design` — create the final single-scope SDD.
10. `140–170` — roadmap, phases, tasks, and separate execution approval.
