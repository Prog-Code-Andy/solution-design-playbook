# Single-Scope Run Sequence

1. `000-start-here` — detect a new project.
2. `010-initialize-project` — create MAIN and YAML state.
3. `020-register-requirements` — register the documentation brief.
4. `025-materialize-requirements-foundation` — only when Windsurf must materialize the reviewed 010/020 Plan.
5. `030-main-discovery` — clarify audience, content, ownership, and success.
6. `040-review-main-discovery` — approve MAIN Discovery.
7. `045-review-requirements-baseline` — approve the Requirements Baseline.
8. `050-decompose-scopes` — approve `single-scope` mode.
9. `080`/`090` — create and accept only durable decisions that are needed.
10. `100-define-contracts` — define content metadata only if an exact boundary is needed.
11. `110-create-main-solution-design` — create the final single-scope SDD.
12. `140–170` — roadmap, phases, tasks, and separate execution approval.
