# Remediation Run Sequence

1. `180-review-delivery` or incident review identifies missing evidence.
2. `190-plan-remediation` confirms impact, evidence, and root cause.
3. Classify whether the problem is a task, REM, new phase, contract change, or new EDR.
4. Draft and review `REM-001` with exact boundaries and targeted verification.
5. Receive `Approve Remediation REM-001` separately.
6. Execute through the target project's authorized workflow.
7. Produce a remediation completion report and leave roadmap phase state unchanged.
