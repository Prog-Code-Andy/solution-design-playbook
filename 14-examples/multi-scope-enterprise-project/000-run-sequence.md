# Multi-Scope Run Sequence

1. `000` and `010` — initialize MAIN.
2. `020` — register the authoritative requirements link and preserve its IDs; use `025` only for Windsurf Plan materialization.
3. `030` and `040` — conduct and approve Main Discovery.
4. `045` — review and approve the Requirements Baseline.
5. `050` — propose and approve multi-scope decomposition.
6. `080–110` — accept cross-cutting decisions/contracts and approve the Main Architecture Baseline.
7. `060` — activate `ENTRA-ID` explicitly.
8. `070` — conduct Entra ID scoped Discovery.
9. `080–100` — accept Entra-specific decisions/contracts as needed.
10. `120` — create and approve `TDD-ENTRA-001`.
11. Repeat `060–120` for the other approved scopes.
12. `130` — integrate TDDs and approve final `SDD-MAIN-001`.
13. `140–170` — roadmap, phases, tasks, and separate execution approval.
