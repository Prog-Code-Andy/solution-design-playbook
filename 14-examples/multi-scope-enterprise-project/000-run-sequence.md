# Multi-Scope Run Sequence

1. `000` and `010` — initialize MAIN.
2. `020` — register the authoritative requirements link and preserve its IDs.
3. `030` and `040` — conduct and approve Main Discovery.
4. `050` — propose and approve multi-scope decomposition.
5. `080–110` — accept cross-cutting decisions/contracts and approve the Main Architecture Baseline.
6. `060` — activate `ENTRA-ID` explicitly.
7. `070` — conduct Entra ID scoped Discovery.
8. `080–100` — accept Entra-specific decisions/contracts as needed.
9. `120` — create and approve `TDD-ENTRA-001`.
10. Repeat `060–120` for the other approved scopes.
11. `130` — integrate TDDs and approve final `SDD-MAIN-001`.
12. `140–170` — roadmap, phases, tasks, and separate execution approval.
