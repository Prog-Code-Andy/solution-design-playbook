# 02 — Discovery

Discovery turns an idea and source material into a reviewable problem definition. It does not approve architecture or authorize implementation.

Use `main-discovery-template.md` first. After Main Discovery and scope decomposition are approved, use `scoped-discovery-template.md` for each selected component or integration.

Separate facts, assumptions, constraints, decisions needed, and open questions. Cite every requirements source and mark inaccessible material as a blocker rather than guessing.
