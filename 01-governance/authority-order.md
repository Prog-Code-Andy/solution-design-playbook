# Authority Order

From highest to lowest authority:

1. Explicit current user instruction within applicable safety and access boundaries.
2. Accepted Engineering Decision Records.
3. Accepted versioned contracts.
4. Approved requirements baseline.
5. Approved Solution Design and applicable TDDs.
6. Approved roadmap.
7. Approved phase specification.
8. Approved task package.
9. Numbered workflow prompt and model adapter.
10. Existing implementation conventions that do not conflict with the above.

Lower-level artifacts cannot override higher-level artifacts. Report a conflict with exact references and stop before mutation.
