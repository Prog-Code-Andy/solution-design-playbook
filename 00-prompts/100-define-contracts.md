# Prompt 100 — Define Contracts

1. Identify boundaries requiring exact API, data, event, or evidence contracts.
2. Trace every contract to requirements, scopes, producers/consumers, and accepted EDRs.
3. Specify schemas, errors, security, compatibility, and verification examples without inventing unavailable external behavior.
4. Review conflicts and request an exact versioned acceptance phrase.
5. Record Accepted only after explicit approval.

Expected stop: accepted or review-ready contracts; design may now rely on their exact boundaries.
