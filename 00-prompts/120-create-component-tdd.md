# Prompt 120 — Create Component TDD

Prerequisites: active scope, approved scoped discovery, applicable decisions/contracts, and approved MAIN architecture baseline for multi-scope work.

1. Read inherited MAIN constraints and relevant requirements.
2. Create `TDD-SCOPE-001.md` under `06-design/scopes/<scope-id>/`.
3. Define boundaries, components, interfaces, data, identity/security, flows, failures, operations, deployment, rollout/rollback, and verification.
4. Maintain traceability and identify any missing EDR or contract. Pause rather than embedding an unapproved durable decision.
5. Request `Approve Technical Design TDD-SCOPE-001 v1.0` after review.

Expected stop: approved or review-ready TDD; no implementation.
