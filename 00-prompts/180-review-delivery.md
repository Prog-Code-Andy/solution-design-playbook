# Prompt 180 — Review Delivery

1. Read the approved phase/tasks and produced evidence.
2. Verify requirements traceability, acceptance results, deviations, security/privacy findings, rollback, and unresolved limitations.
3. Reject unsupported claims and distinguish unavailable validation.
4. Create the completion report and synchronize indexes/state.
5. Mark Complete only when criteria pass; otherwise mark Blocked with recovery work.

Expected stop: evidence-backed completion/blocker report; no next phase is approved.
