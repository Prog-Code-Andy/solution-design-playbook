# Prompt 020 — Register Requirements

Prerequisites: initialized project control files and at least one user-provided source location.

1. Read `03-requirements/README.md` and intake/source templates.
2. Attempt read-only access to each source using available authorized tools. If inaccessible, request an export or pasted content; do not guess.
3. Record source metadata, ownership/version when known, access limitations, and canonical status.
4. Preserve source-defined requirement IDs. Propose local aliases only where IDs do not exist.
5. Create/update intake and requirements analysis drafts plus YAML registries.
6. Identify contradictions, ambiguity, sensitive content, missing acceptance criteria, and candidate scope mappings.

Expected stop: source inventory and analysis draft are ready; `next_prompt` is `030-main-discovery` unless blocked.
