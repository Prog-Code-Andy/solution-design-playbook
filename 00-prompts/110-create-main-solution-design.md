# Prompt 110 — Create Main Solution Design

1. Read all approved MAIN discovery, requirements, scopes, accepted EDRs, and contracts.
2. Create/update `SDD-MAIN-001.md` using the solution-design template.
3. Cover system context, responsibilities, integrations, end-to-end flows, security, data, deployment, operations, risks, and TDD index.
4. For multi-scope projects, first seek `Approve Architecture Baseline SDD-MAIN-001 v0.1` so scoped TDD work can begin.
5. Do not claim final integrated approval until component TDDs and prompt 130 review are complete.

Expected stop: approved baseline or a bounded revision list.
