# Prompt 090 — Review Decisions

1. Check each Proposed EDR for a real decision, alternatives, trade-offs, scope, downstream effects, and conflicts.
2. Present unresolved issues and a concise recommendation.
3. Request a separate exact `Accept EDR-NNN` message for each record or an explicitly enumerated batch.
4. After valid acceptance, record status/date and update indexes. Never edit accepted content; later material change requires a new EDR.

Expected stop: decisions accepted or returned for revision; no implementation authorization.
