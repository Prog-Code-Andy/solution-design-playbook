# Prompt 130 — Review Integrated Design

1. Compare the Main SDD with every in-scope TDD, accepted EDR, contract, and requirements baseline.
2. Check interface, identity, data ownership, lifecycle, deployment, observability, and failure consistency.
3. Update the Main SDD only through a reviewed version; never rewrite accepted decisions/contracts.
4. Produce an integrated design review report and unresolved-action list.
5. When complete, request `Approve Solution Design SDD-MAIN-001 v1.0`.

Expected stop: integrated design approved or blocked with exact conflicts.
