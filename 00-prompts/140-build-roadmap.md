# Prompt 140 — Build Roadmap

1. Use approved requirements and designs plus accepted EDRs/contracts.
2. Order outcomes by dependency and risk; separate included, deferred, and excluded work.
3. Define checkpoints and verification themes without authorizing implementation.
4. Update traceability and request `Approve Roadmap v1.0` after review.

Expected stop: approved roadmap; no phase is automatically approved.
