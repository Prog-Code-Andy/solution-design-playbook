# Prompt 150 — Build Phases

1. Decompose the approved roadmap into bounded phases with explicit dependencies.
2. For every phase, define scope, exclusions, requirements, governing artifacts, deliverables, acceptance criteria, verification, rollback, reports, and stop condition.
3. Ensure later-phase functionality is not authorized early.
4. Build a phase index and request approval of the phase package.

Expected stop: approved phase specifications; Phase 00 still requires its own explicit approval.
