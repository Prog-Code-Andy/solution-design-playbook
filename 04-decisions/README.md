# 04 — Engineering Decision Records

EDR is the umbrella format for durable architecture, product, privacy, security, data, process, operations, quality, and design decisions. Do not create a duplicate ADR for an architecture-category EDR.

An accepted EDR is immutable. A changed decision requires a new EDR that names what it amends or supersedes. Designs, contracts, roadmaps, phases, and tasks must comply with accepted EDRs.
